# BlockMark

在 Minecraft 中建造你的超市！BlockMark 为 Minecraft 1.20.4（Fabric）添加了完整的超市系统——21 种专用方块、67 种商品物品、14 个交互 GUI，涵盖货架、制冷设备、收银设备和超市设施。

## 特性

- **21 个超市方块**：7 种货架、4 种制冷设备、5 种收银设备、5 种设施
- **67 种商品物品**：水果、肉类海鲜、烘焙、零食、饮料、粮油调味、日用品等 18 个分类
- **14 个交互 GUI**：货架和制冷设备可存放商品，收银台提供独立物品栏
- **完整方块属性**：朝向、含水、制冷点亮、碰撞箱、红石比较器输出、网络同步
- **中英双语**：完整的中英文语言文件
- **双端通用**：同时支持客户端和专用服务器

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/) 和 [Fabric API](https://modrinth.com/mod/fabric-api)
2. 下载 `BlockMark-1.0.0.jar`
3. 放入 `.minecraft/mods/` 目录
4. 启动游戏

## 使用

所有货架、制冷设备和收银台都支持右键打开 GUI：

- **放入物品**：将商品物品拖入物品栏槽位
- **取出物品**：从物品栏拖出，或使用 Shift + 点击快速存取
- **快速转移**：Shift + 点击可在方块物品栏和玩家背包间快速转移物品

## 构建

```bash
git clone <repository-url>
cd BlockMark
./gradlew build
```

构建产物位于 `build/libs/`。
